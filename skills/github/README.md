# GitHub

GitHub 数字资产管理。

- **[github-asset-manager](./github-asset-manager/SKILL.md)** — 整理和改善 GitHub 数字资产。通过 GitHub CLI 或 `GITHUB_TOKEN` 读取数据，提供多个本地分析命令：分析并分类 GitHub Stars、审计个人仓库健康度、生成 GitHub Profile README、润色仓库 README、生成多语言 README、为指定仓库补全描述与 topics，以及将 Stars 整理进 GitHub Lists。所有写操作（更新 About、推送 README、应用 Star Lists）都需要用户明确确认，默认只输出结构化 Markdown 报告。
